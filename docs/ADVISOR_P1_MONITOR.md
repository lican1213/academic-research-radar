# 导师重点课题：区位多元布局与跨国供应链韧性 — 文献雷达监测规格

更新时间：2026-11-22。**本文件仅是公开文献发现配置**，不是论文评审、结论认可或修改建议。研究画像由用户提供的最新材料包中“导师核心思想与 V3.2 对照说明”及 v3.4 工作稿的研究问题抽象得到，**不存放未发表稿、实证数值、CSV、导师语音或私人文件**。

## 目标与边界

沿“**大国博弈约束 → 自主开放引领 → 有序跨境布局 → 风险前置管控 → 韧性提升**”监控经济学、国际商务和供应链实证研究。主问题：美国实体清单/出口管制冲击下，**冲击前已有的企业海外子公司国别区位组合**与**境外上游供应伙伴存续、退出、新进入、替代、来源国分散**的研究进展，区别于企业整体国际化规模；以美国加征关税对下游需求、第三国制造布局和单点集聚风险的研究作对照。

- **冲击轴**：Entity List；BIS export controls；export restrictions；2018 Section 301 tariffs；2022 semiconductor controls；2025 reciprocal tariffs；直接/间接供应链暴露。分清出口管制（上游供给）与进口关税（下游需求），区分政策公布、执行、预期及提前调整。
- **布局轴**：事前 foreign subsidiaries/affiliates、OFDI host-country diversification、单国与多国节点、子公司总数、东道国制度差异、海外制造/销售服务/研发资源职能；对照海外营收、资产与投资规模。
- **伙伴轴**：跨国 buyer–supplier link、foreign upstream supplier stock、relationship survival/termination、new supplier entry、partner switching、third-country sourcing、repeated/recovered links、来源国集中度。区分 FactSet Revere 记录关系与实际进出口/采购金额。
- **重点产业链**：集成电路/半导体、新能源汽车、生物医药；行业技术密集度、投入品关系专用性与关键环节映射。不能只凭宽行业代码推定关键环节。
- **经济学识别轴**：staggered DID、Sun–Abraham、Callaway–Sant’Anna、imputation、honest DID、PPML 与计数/稀疏变量、预趋势与安慰剂、事件提前调整、对照组可比性、企业经营规模/国际化程度、供应关系数据库覆盖变化。只监控相关文献与公开复现资源；不把这些方法自动视为有效。

## 来源与职责

1. GitHub Actions 仍只做 Crossref、arXiv、中文九刊的**公开题录增量**与既有去重；`radar.py` 在 P1/P1A 增加实体清单、上游供应伙伴及区位多元组合查询。每日候选上限、P0优先级、原有 cron、状态含义均不变。
2. ChatGPT 每日研究雷达依原任务对九刊逐刊核对，同时补检《世界经济研究》《国际贸易问题》的官方文章级页，以及 RePEc、NBER、CEPR、OpenAlex 和相关英文经济学/国际商务出版方。中文关键词：实体清单、出口管制、间接暴露、跨境供应链、境外上游、供应商进入/退出、区位多元布局、海外子公司、单点集聚、关键产业链。
3. **Undermind（用户授权的工作区）**作为按需语义/引用网络补漏源：优先读现有“导师课题：实体清单—事前区位多元—跨国上游伙伴调整” deep search，检索其新发现及重点论文的引用/版本；有强信号时再进行少量定向搜索。免费账户额度、连接失败时不得声称覆盖。**不在无凭据 GitHub Runner 中直接发起 Undermind 登录或深度搜索；不向仓库提交 OAuth Token。**
4. 归一化先 DOI，其次标题+作者+年份、arXiv ID；保留论文首次发表日期与 Undermind/GitHub 首次发现日期的差异。Undermind workspace cite_key 只在该工作区唯一，**不能当跨系统 DOI**。
5. 日报只有真正高价值研究出现才新增条目（0—3 重点、0—2 观察）；可写“Undermind 补漏、与 GitHub 重复、旧文献重检、全文不可得”。**日报是文献监测报告，不是导师论文审稿报告**，不按未发表稿件数字逐表评判。

## 验收和安全边界

- **回归测试**：出口管制×境外上游、OFDI×区位多元×韧性、海外节点×供应商进入必须召回；纯出口许可合规与泛化 FDI 增长必须排除；P0 排序及上限不变。
- **GitHub 生产**：以同 SHA CI+真实 scan+最新提交文件回读为完全生产验收；PR 合并或单次语义检索不等于自动监控可用。
- **Undermind**：保存的深度检索状态、实际结果、免费额度/授权状态需要分别确认；一次深搜启动不等于持续自动运行。无法连接时监测仍走 Github 和公开来源。
- **资料安全**：禁止推送私人论文、导师访谈原音频、FactSet/CSMAR 原始数据、付费全文或个人密钥。
